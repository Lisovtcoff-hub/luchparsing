# 📦 LuchParsing — сервис расчёта стоимости доставки

## Назначение
Веб-сервис для автоматизированного расчёта стоимости доставки грузов у транспортных компаний с:
- параллельным запуском расчётов,
- историей запусков,
- сравнением с предыдущим расчётом,
- экспортом результатов в XLSX.

Проект реализован на **Python + FastAPI**, с веб-панелью управления и SQLite в качестве БД.

---

## 🔧 Технологии
- Python 3.10+
- FastAPI
- SQLite
- httpx / asyncio
- (опционально) Selenium — для сайтов без API
- Uvicorn

## ⚙️ Установка

### 1. Создание виртуального окружения
```bash
python -m venv .venv
source .venv/bin/activate      # Linux / macOS
.venv\Scripts\activate       # Windows
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка доступа в панель
В файле `.env` укажите логин и пароль для доступа в веб-панель:

```env
PANEL_USER=admin
PANEL_PASSWORD=strong_password
```

## 🧮 Как работает расчёт

1. Пользователь задаёт маршруты и пресеты(они храняться в базе даже после перезапуска).
2. Нажимает **«Запустить расчёт»**.
3. Создаётся `job`, который:
   - запускает адаптеры параллельно,
   - пишет результаты в БД,
   - считает прогресс.
4. Результаты:
   - отображаются в интерфейсе,
   - сравниваются с предыдущим запуском,
   - могут быть экспортированы в XLSX.

---

## 🔄 Сравнение с предыдущим запуском
При каждом расчёте система автоматически:
- находит предыдущий успешный `job`,
- сравнивает цены по `(site, route, preset)`,
- помечает изменения (рост / падение / без изменений).

## 📊 Экспорт в Excel
Кнопка **«Экспорт .xlsx»** выгружает результаты текущего расчёта
с дельтами относительно предыдущего запуска.

## 🧩 Добавление нового перевозчика (адаптера)

### 1. Создать файл адаптера
```
parsers/mycarrier.py
```

### 2. Реализовать класс
```python
from core.contracts import CarrierAdapter, CalcParams, CalcResult

class MyCarrierAdapter(CarrierAdapter):
    code = "mycarrier"
    name = "Мой перевозчик"

    async def calc(self, client, params: CalcParams) -> CalcResult:
        return CalcResult(
            price=1234.56,
            days="2-4",
            name_tarif="Базовый",
            allowances=None
        )
```

### 3. Зарегистрировать адаптер
Добавьте адаптер в список используемых в `start_calc.py`
или месте сборки адаптеров.

Адаптер должен быть асинхронным и не хранить состояние между вызовами.

## 🚨 Обработка ошибок
- Ошибки адаптеров логируются.
- Последняя ошибка сохраняется в `sites_config.last_error`.
- При частых сбоях сайт временно блокируется (circuit breaker).

---

## 🔐 Безопасность
- Панель защищена Basic Auth.
- Данные доступа хранятся в `.env`.
- `.env` не должен попадать в репозиторий.
